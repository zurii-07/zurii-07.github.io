# Portfolio

Static portfolio site for GitHub Pages.

## Deploy

1. Create a public repo named `YOUR_USERNAME.github.io` (this gives you the root URL `https://YOUR_USERNAME.github.io`). Any other repo name works too, but then the site lives at `https://YOUR_USERNAME.github.io/REPO_NAME`.
2. Upload `index.html`, `style.css` and this `README.md` to the repo root.
3. In the repo go to **Settings > Pages**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait a minute or two, then open the URL shown on the Pages settings screen.

## Before publishing

- Replace `YOUR_EMAIL@example.com`, `YOUR_USERNAME` and `YOUR_LINKEDIN` in `index.html`.
- Get your employer's OK for the project descriptions, and make sure no credentials, customer names or confidential figures appear.
